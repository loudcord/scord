FULLSCREEN PRANK — проект

Файлы:
- index.html — страница
- assets/image.png — загруженная картинка
- assets/sound.mp3 — загруженный звук (повторяется по кругу)

Публикация на GitHub Pages:
1. Создай публичный репозиторий, например fullscreen-prank.
2. Загрузи ВЕСЬ контент этой папки, сохраняя структуру: index.html и папку assets.
3. Открой Settings → Pages.
4. В Build and deployment выбери Deploy from a branch, Branch: main, Folder: /(root), нажми Save.
5. Подожди публикации; GitHub покажет адрес сайта.

Важно:
- Браузер не разрешает включать fullscreen и звук до действия пользователя, поэтому сначала будет кнопка «Открыть».
- Esc нельзя заблокировать. После выхода из fullscreen появится страница-предупреждение с кнопками.
- При закрытии вкладки браузер может показать только своё стандартное предупреждение; сайт не может гарантированно удерживать пользователя.
